5. Apa itu Anonymous Functions?

   Jawaban : Anonymous function adalah function tanpa nama, biasanya digunakan sekali. Sintaks menggunakan () { } atau panah =>

6. Jelaskan perbedaan Lexical scope dan Lexical closures!

   Jawaban :

   Lexical Scope: ruang lingkup variabel ditentukan berdasarkan letak kode di file

   Lexical Closure: function dalam function dapat mengakses variabel dari scope di luar function-nya, bahkan setelah scope luar selesai dieksekusi.
